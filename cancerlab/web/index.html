WORKSPACE GUIDE
Evidence first. Predictions second.
Choose a patient, organ, and evidence cutoff. Inspect observations, seal all three baseline forecasts, then explicitly reveal the later examination. The saved prediction never changes.
Keyboard & navigation
/ Find patient · ? Open this guide · Esc Close a dialog. Use arrow keys within workspace tabs. Every action also has a visible control.
Connect your own local data
The demo contains synthetic measurements. To inspect real CT files, start the server with imported patient records and a local scan directory:
python -m cancerlab serve --patients /path/to/patients --scan-root /path/to/CancerVerse
Paths are examples. Import and review the data first. This interface does not upload patient files to a cloud service.
Keep observed and predicted separate
Teal marks measurements; amber marks forecasts. Spheres encode volume, not anatomy. The CT viewer shows source scans and measured masks only. Unknown coverage is not absence of disease.
